# Nyx Canvas v2.5 — οδηγός

**Νέα στο v2.5:** Απόδοση (RAM/VRAM/θερμοκρασία), Πίνακας μοντέλων, Πρόσωπα v1, sd-server Start/Stop, Router v2 με Groq,
«Ιδιωτικό», Θέματα v2 (επεξεργαστής + ανατολή/δύση), εργαλεία φωτογράφου, βοηθός σαν agent. Όλα τα νέα είναι **κλειστά**
μέχρι να τα ρυθμίσεις. Ο καμβάς και τα δεδομένα σου δεν αλλάζουν.

## Α. Αναβάθμιση από v2.4
1. Κατέβασε το `nyx-2.4.0-to-2.5.0.zip`. **Μην** το αποσυμπιέσεις.
2. Nyx → **Ρυθμίσεις → Ενημερώσεις → «Εγκατάσταση από αρχείο…»** → διάλεξε το zip.
3. ✅ → «Επανεκκίνηση τώρα». Στις Ενημερώσεις γράφει **v2.5.0**. Επαναφορά: «Επαναφορά στην προηγούμενη έκδοση».
Το `nyx-2.5.0-full.zip` μπαίνει με τον ίδιο τρόπο σε οποιαδήποτε 2.1.x – 2.4.x.

## Β. Τι άλλαξε
* **Απόδοση** (Ctrl+Shift+M): RAM, VRAM, φόρτος GPU, θερμοκρασία, μνήμη ανά διεργασία. Η θερμοκρασία GPU στα Windows
  χρειάζεται το **LibreHardwareMonitor** ανοιχτό (αλλιώς γράφει «—»).
* **Πίνακας μοντέλων** (Ctrl+K → «Μοντέλα (GGUF)» ή AI Hub → Εργαλεία v2.5): όλα τα `.gguf`, quant, αν χωράει στα 24 GB της 7900 XTX, μέγιστο context,
  διπλότυπα. «Φόρτωση» = το βάζει στο llama-server.
* **sd-server**: AI Hub → Τοπικοί servers → sd-server → exe (`sd-server.exe` από stable-diffusion.cpp, Vulkan), φάκελος
  μοντέλων, φάκελος LoRA → **Εκκίνηση**. «Web UI» (ή Ctrl+K «sd-server: άνοιγμα web UI») = το δικό του UI με επιλογή μοντέλου/LoRA. Μόνο 127.0.0.1.
* **Router v2**: AI Hub → «Router v2» → ρόλοι γρήγορο / όραση / χωρίς λογοκρισία (Qwen3.6, Qwen3.8, Gemma 4). Αν ο τοπικός
  server δεν απαντά, πάει στο Groq (αν έχεις βάλει κλειδί).
* **«Ιδιωτικό»** (🎭 στον βοηθό): η συζήτηση μένει μόνο στη μνήμη και σβήνει όταν βγεις. Venice ζητά επιβεβαίωση κόστους.
* **Πρόσωπα** (Ctrl+Shift+U): πρώτα συναίνεση, μετά κατέβασμα μοντέλων με κλικ (YuNet + SFace από OpenCV Zoo, έλεγχος sha256). Σάρωση → ονόμασε άτομα →
  Ctrl+K «Μαρία» βρίσκει τις φωτογραφίες της. Όλα τοπικά. Χρησιμοποίησέ το μόνο σε φωτογραφίες με άδεια των εικονιζόμενων.
* **Θέματα v2**: Ctrl+K → «Επεξεργαστής θέματος» / «Θέμα μέρας/νύχτας». Ανατολή/δύση για Αθήνα από προεπιλογή.
* **Φωτογράφος**: Ctrl+K → «Τα μοντέλα & LoRA μου» (ρυθμιστικά έντασης → `<lora:όνομα:ένταση>`), «Φωτογραφίσεις & μοντέλα»
  (φάκελος φωτογράφισης + φόρμα συναίνεσης), «Πριν / Μετά» (← → ή σύρσιμο), «Μαζική βελτίωση / upscale».
* **Βοηθός**: μνήμη (τοπικά), δεξιότητες, αναίρεση, συνημμένα (📎), web agent που δεν πληκτρολογεί ποτέ κωδικούς/κάρτες/OTP.
* **Υπηρεσίες**: AI Hub → «Οι υπηρεσίες σου» με σύσταση για καθεμία.

## Γ. Γιατί όχι ComfyUI
Θέλει Python + ROCm στα Windows (βαρύ, εύθραυστο, αργό στο στήσιμο). Το **sd-server** είναι ένα exe, native Vulkan, με
δικό του web UI και επιλογή μοντέλου/LoRA — καλύπτει τη ροή φωτορεαλισμού χωρίς Python.

## Δ. Τι δεν έχει δοκιμαστεί σε πραγματικό υλικό
Sogni live (χωρίς κλειδί — δοκιμή με offline ψεύτικο client), θερμοκρασία GPU χωρίς LibreHardwareMonitor, hex (μόνο macOS),
sd-server txt2img/LoRA σε αληθινό server (δοκιμή με ψεύτικο server), πραγματικά μοντέλα όρασης/whisper.
Το Google Sheet **δεν χρησιμοποιείται**.
