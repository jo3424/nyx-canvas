ΕΚΚΙΝΗΣΗ (χωρίς εγκατάσταση, χωρίς Python, χωρίς cmd)
 1. Κάνε δεξί κλικ στο zip → «Εξαγωγή όλων» σε έναν φάκελο που θα μείνει
    (π.χ. C:\Users\<εσύ>\Apps\NyxCanvas). ΜΗΝ το τρέχεις μέσα από το zip.
 2. Διπλό κλικ στο NyxCanvas.exe. Ανοίγει σαν κανονικό παράθυρο εφαρμογής.
 3. Προαιρετικά: δεξί κλικ στο NyxCanvas.exe → «Εμφάνιση περισσότερων επιλογών»
    → «Αποστολή προς → Επιφάνεια εργασίας (δημιουργία συντόμευσης)».

⚠ WINDOWS SMARTSCREEN
 Η εφαρμογή δεν είναι ψηφιακά υπογεγραμμένη (το certificate κοστίζει),
 οπότε την πρώτη φορά τα Windows μπορεί να δείξουν μπλε παράθυρο
 «Τα Windows προστάτευσαν τον υπολογιστή σας».
 → Πάτα «Περισσότερες πληροφορίες» → «Εκτέλεση οπωσδήποτε». Μόνο μία φορά.
 Αν δεν ανοίγει καθόλου: δεξί κλικ στο zip → Ιδιότητες → τσέκαρε «Κατάργηση
 αποκλεισμού» (Unblock) → OK, και κάνε ξανά εξαγωγή.

WIDGET
 • Ctrl+Alt+N από οπουδήποτε: ανοίγει/κλείνει το widget (πάντα από πάνω).
 • Ctrl+Alt+Space: φέρνει μπροστά τον καμβά.
 • Το εικονίδιο στο tray (κάτω δεξιά, δίπλα στο ρολόι) έχει: widget,
   click-through (το widget γίνεται «διάφανο» στα κλικ), εκκίνηση με τα Windows,
   Έξοδος. Το Χ του παραθύρου ΔΕΝ κλείνει την εφαρμογή — συνεχίζει στο tray για
   να χτυπάνε οι υπενθυμίσεις (αλλάζει από τις Ρυθμίσεις).
 • Στο widget: γρήγορη σημείωση (Enter), επόμενες υπενθυμίσεις / countdowns /
   επεισόδια, συνδρομές και ό,τι έχεις «καρφιτσώσει» (δεξί κλικ σε κάρτα → Καρφίτσωμα).

ΒΑΣΙΚΑ
 • Ροδέλα = ζουμ, Space ή μεσαίο κλικ + σύρσιμο = μετακίνηση, Shift+1 = δες τα όλα.
 • Διπλό κλικ οπουδήποτε = γράψε. Ctrl+K = αναζήτηση & εντολές. Ctrl+E = emoji/stickers/εικονίδια/memes.
 • Σύρε εικόνες, βίντεο, ήχους, αρχεία, links κατευθείαν από τα Windows/browser. Ctrl+V επικολλά εικόνες.
 • Memes: η εφαρμογή ΔΕΝ περιέχει memes τρίτων (πνευματικά δικαιώματα) — πρόσθεσε
   τα δικά σου από Βιβλιοθήκη → Memes → Εισαγωγή (ή σύρε τα εκεί) και μένουν για πάντα.
 • Σειρές: countdown επόμενου επεισοδίου από το TVmaze (δωρεάν, χωρίς κλειδί).
   Ταινίες: χειροκίνητα ή με δικό σου δωρεάν TMDB API key (Ρυθμίσεις).
 • Tracking: παρακολουθεί μια σελίδα για λέξη/όνομα κάθε λίγα λεπτά. Στο v2
   χρησιμοποιεί το session του ενσωματωμένου browser (Ctrl+B), άρα βλέπει και σελίδες με login.

ΠΟΥ ΑΠΟΘΗΚΕΥΟΝΤΑΙ ΤΑ ΔΕΔΟΜΕΝΑ
 %APPDATA%\Nyx Canvas\data\nyx.json  (+ φάκελος media με τις εικόνες/ήχους σου)
 Αποθηκεύει αυτόματα. Κράτα αντίγραφα: Ρυθμίσεις → Εξαγωγή backup.
 Αν μεταφέρεις/ενημερώσεις τον φάκελο της εφαρμογής, τα δεδομένα δεν χάνονται.
