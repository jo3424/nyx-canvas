Δοκιμή αποδοχής — Nyx Canvas 2.7.0 (widgets + 4 διορθώσεις)
Ημερομηνία: 19/11/2026. Ζώνη ώρας: Europe/Athens.
Το PC σου είναι στην 2.6.13.1. Δεν αλλάζει τίποτα σε router, μοντέλα, GPU-Voice-Studio. Χρησιμοποίησε ΠΡΑΓΜΑΤΙΚΟ ποντίκι.

Εγκατάσταση
- Πριν: Ιστορικό → «Τώρα» (snapshot).
- Ρυθμίσεις → Ενημέρωση → nyx-2.6.13.1-to-2.7.0.zip. Σε άλλη έκδοση απορρίπτεται («λάθος βάση») χωρίς να αλλάξει τίποτα.
- Μετά: Ρυθμίσεις → Ενημέρωση → έκδοση 2.7.0.

Α. Τίποτα δεν χάθηκε
1. Πίνακες, κάρτες, συνδρομές, Κάδος, Ιστορικό, MCP, ρυθμίσεις: όπως πριν.
2. Hub: ctx 32768, μέγιστο 1 μοντέλο, router / μοντέλα όπως πριν. Στείλε ένα μήνυμα στον βοηθό → ο Qwen απαντά με ~59–63 t/s
   όπως στην 2.6.13.1 (η 2.7.0 δεν αγγίζει router / GPU).

Β. Συλλογή «Προσθήκη widget» (mockup 09)
1. Πάνω μπάρα: νέο κουμπί με εικονίδιο πλέγματος (πριν από το «Widget»), tooltip «Widgets — συλλογή «Προσθήκη widget»». Κλικ → παράθυρο «Προσθήκη widget».
2. Αριστερά: Όλα 11 / Έτοιμα 5 / Ζωντανές ροές 3 / Δικά μου 3. Έτοιμα: Σήμερα, Συνδρομές, Υπενθυμίσεις, Ημερολόγιο, Ετικέτα.
3. RSS, YouTube, Καιρός, Νερό, Φτιάξε δικό σου, Άλλη ροή: γκρίζα, χωρίς «+ Προσθήκη», γράφουν «έρχεται στην 2.7.1 / 2.7.2»
   (ο Καιρός «θέλει απόφασή σου (νέο URL)»).
4. Στις «Υπενθυμίσεις» πάτα «Μεγ.» και μετά «+ Προσθήκη» → το παράθυρο κλείνει, εμφανίζεται μεγάλο widget στη μέση του καμβά.
5. Αριστερή μπάρα «+» → τελευταία γραμμή «Widget…» → ανοίγει η ίδια συλλογή. Esc την κλείνει.
6. Πρόσθεσε και τα άλλα τέσσερα (Σήμερα, Συνδρομές, Ημερολόγιο, Ετικέτα).

Γ. Τα widgets με τα δικά σου δεδομένα (mockup 08)
1. Συνδρομές: το σύνολο του μήνα = ίδιο ποσό με το πάνελ Συνδρομών· «από N ενεργές»· μπάρα πληρωμένα / υπόλοιπα· οι επόμενες
   χρεώσεις. Κλικ στο ποσό ή σε γραμμή → ανοίγει το πάνελ Συνδρομών.
2. Υπενθυμίσεις: οι επόμενες με «σε 2 ώρες» / «αύριο» / «σε 4 μέρες». Κλικ σε γραμμή → ο καμβάς πάει στην κάρτα (και σε άλλο πίνακα).
3. Ημερολόγιο: σήμερα τονισμένο, τελείες στις μέρες με χρέωση / υπενθύμιση. › και ‹ αλλάζουν μήνα. Κλικ σε μέρα → κάτω γράφει τι έχει.
4. Σήμερα: η ημερομηνία και ό,τι λήγει σήμερα· «Αύριο: N».
5. Ετικέτα: ⋯ → «Αλλαγή ετικέτας» → γράψε μια ετικέτα που χρησιμοποιείς (ή διάλεξε από τις προτάσεις) → OK → οι κάρτες με την ετικέτα
   από όλους τους πίνακες. Κλικ σε γραμμή → πάει στην κάρτα.
6. Άλλαξε κάτι (π.χ. πρόσθεσε υπενθύμιση σε μια κάρτα) → το widget ενημερώνεται μόνο του σε λίγα δευτερόλεπτα.

Δ. Ποντίκι: σύρσιμο, μέγεθος, μενού ⋯ (mockup 12)
1. Σύρε ένα widget από την κεφαλίδα (τον τίτλο) → μετακινείται. Ctrl+Z → γυρίζει πίσω.
2. Σύρσιμο που ξεκινά μέσα στο περιεχόμενο (σε γραμμή) → ΔΕΝ μετακινεί το widget.
3. Κλικ στην κεφαλίδα → λαβές· τράβα την κάτω δεξιά → μεγαλώνει.
4. ⋯ → Μέγεθος: Μικρό / Μεσαίο / Μεγάλο → αλλάζει μέγεθος (✓ στο τρέχον).
5. ⋯ → Σύμπτυξη → μένει μόνο η κεφαλίδα· ⋯ → Ανάπτυξη → γυρίζει.
6. ⋯ → «Καρφίτσωμα στο παράθυρο Widget» → ✓· άνοιξε το παράθυρο Widget (Ctrl+Alt+N ή το κουμπί «Widget») → το widget φαίνεται
   με τον τίτλο του ανάμεσα στις καρφιτσωμένες κάρτες (το περιεχόμενό του εκεί έρχεται στην 2.7.2).
7. ⋯ → Κλείδωμα → δεν σέρνεται· ξανά → ξεκλειδώνει.
8. ⋯ → «Αφαίρεση → Κάδος» (κόκκινο) → το widget φεύγει, ο Κάδος κάτω αριστερά +1. Ctrl+Z → γυρίζει, ο Κάδος −1.
9. Μικρό παράθυρο (~1024 πλάτος): συλλογή και μενού ⋯ μέσα στο παράθυρο, τίποτα κομμένο.

Ε. Διορθώσεις
1. (α) Hub → Μοντέλα: η κάρτα του Qwen3.8-27B-UD-Q4_K_XL γράφει ~17,7 GB (όχι 1,7 GB). Σύγκρινε με το μέγεθος του .gguf
   στην Εξερεύνηση (Μέγεθος σε GB, όχι «μέγεθος στον δίσκο»).
2. (β) Hub → Κατάσταση: η κάρτα VRAM γράφει π.χ. «18,x GB» και από κάτω «από 24,0 GB · llama-server …». Πέρνα το ποντίκι από
   την κάτω γραμμή → tooltip με όλες τις διεργασίες. Σύγκρινε με Διαχειριστή εργασιών → Λεπτομέρειες → στήλη «Αποκλειστική μνήμη GPU».
   Hub → Μοντέλα: το chip «VRAM» του φορτωμένου Qwen ≈ η αποκλειστική μνήμη GPU του llama-server.
3. (γ) Φτιάξε πίνακα «Δοκιμή» με 2 κάρτες → διάγραψέ τον (OK) → ο Κάδος +2.
   - Ctrl+Z (ή το κουμπί αναίρεσης) → ο πίνακας γυρίζει με τις 2 κάρτες, ο Κάδος −2 αμέσως.
   - Ξανά διαγραφή → «Αναίρεση» στο μήνυμα → το ίδιο, ΕΝΑ μόνο αντίγραφο του πίνακα.
   - Διάγραψε τον «Δοκιμή» στο τέλος (οι 2 κάρτες πάνε στον Κάδο — άδειασέ τον αν θέλεις).
4. (δ) Με ανοιχτό το GPU-Voice-Studio: άνοιξε τη συνομιλία του βοηθού → ΔΕΝ γράφει τίποτα για «Voice Studio».
