Δοκιμή αποδοχής — Nyx Canvas 2.6.13.1 (χωρίς τοπική φωνή) + αυτόματο κύλισμα καρτελών
Ημερομηνία: 18/11/2026. Ζώνη ώρας: Europe/Athens.
Δεν χρειάζεσαι Voice Studio ούτε OmniVoice. Το PC σου είναι στην 2.6.13. Η εγκατάσταση του GPU-Voice-Studio ΔΕΝ αλλάζει.

Εγκατάσταση — ποιο zip
- Το PC σου είναι στην 2.6.13 → βάλε το nyx-2.6.13-to-2.6.13.1.zip (Ρυθμίσεις → Ενημέρωση). ΑΥΤΟ είναι το κύριο.
  Σε άλλη έκδοση το patch απορρίπτεται («λάθος βάση») χωρίς να αλλάξει τίποτα.
- (Δευτερεύον, μόνο αν κάπου έχεις ακόμα 2.6.12.2: nyx-2.6.12.2-to-2.6.13.1.zip. Στο PC σου ΔΕΝ χρειάζεται.)
- Πριν: Ιστορικό → «Τώρα» (snapshot).
- Πριν (για το βήμα Β): σημείωσε τι γράφει τώρα το Ρυθμίσεις → Ομιλία → «Σύνθεση φωνής (TTS)».
- Μετά: Ρυθμίσεις → Ενημέρωση → έκδοση 2.6.13.1.

Α. Φόρτωση χωρίς αλλαγές στα δεδομένα
1. Άνοιξε το Nyx. Πίνακες, κάρτες, συνδρομές, Κάδος, Ιστορικό, MCP: όπως πριν.
2. Hub: ctx 32768, μέγιστο 1 μοντέλο, router / μοντέλα όπως πριν.

Β. Η ρύθμιση ομιλίας και το μήνυμα (μία φορά)
1. Στην 2.6.13 είχες «Τοπικός server: vs-engine — GPU-Voice-Studio / OmniVoice» με «Φωνή απάντησης» (ster) και «Μηχανή 7802».
   (Το ίδιο ισχύει και για «Εξωτερική εντολή» με vs-engine.exe / omnivoice-tts.exe.)
   με την 1η εκκίνηση της 2.6.13.1 βλέπεις κάτω στη μέση μήνυμα (μένει ~30 δευτ., έχει κουμπί «Ομιλία» και ×):
   «🔇 Η ομιλία γύρισε σε «Χωρίς φωνή»: η τοπική φωνή (vs-engine / OmniVoice) αφαιρέθηκε στην 2.6.13.1, γιατί φόρτωνε την GPU.
    Το Nyx δεν την ξεκινά πια. Τίποτε άλλο δεν άλλαξε (πίνακες, κάρτες, συνδρομές ίδια). Μπορείς να διαλέξεις τις φωνές των Windows
    στις Ρυθμίσεις → Ομιλία.»
   Αν πριν ήταν «Φωνές Windows / συστήματος»: δεν αλλάζει τίποτα και δεν βγαίνει μήνυμα.
2. Ρυθμίσεις → Ομιλία → «Σύνθεση φωνής (TTS)» = «Χωρίς φωνή», με από κάτω τη σημείωση «Το Nyx δεν μιλάει. …».
3. Άνοιξε τη λίστα: «Χωρίς φωνή» / «Φωνές Windows / συστήματος (ελληνική φωνή αυτόματα)» / «Εξωτερική εντολή (π.χ. Piper)».
   ΔΕΝ υπάρχει «Τοπικός server: vs-engine». Δεν υπάρχουν «Φωνή απάντησης», personas, «Έλεγχος 7802», token, «Log φωνής».
4. «Δοκιμή φωνής» με «Χωρίς φωνή» → μήνυμα «Η ομιλία είναι «Χωρίς φωνή» — δεν μιλάω.»
5. Κλείσε τελείως και ξανάνοιξε το Nyx → το μήνυμα του Β1 ΔΕΝ ξαναβγαίνει.
6. Μικρό παράθυρο (~1024 πλάτος): τα ίδια, τίποτα κομμένο.

Γ. Το Nyx δεν ξεκινά ποτέ vs-engine (Διαχειριστής εργασιών → Λεπτομέρειες, ταξινόμηση κατά όνομα)
Κράτα ανοιχτό τον Διαχειριστή εργασιών σε όλο το Γ. ΔΕΝ πρέπει να εμφανιστεί καινούργιο vs-engine.exe ή omnivoice-tts.exe από το Nyx.
(Αν το Voice Studio / ο Hermes τρέχει δικό του vs-engine, αυτό υπάρχει ήδη πριν ανοίξεις το Nyx· σημείωσε το PID του — δεν πρέπει να
 εμφανιστεί δεύτερο.)
1. Εκκίνηση του Nyx → κανένα νέο vs-engine.exe.
2. Ρυθμίσεις → Ομιλία: άλλαξε «Σύνθεση φωνής» Χωρίς φωνή → Φωνές Windows → Εξωτερική εντολή → Χωρίς φωνή → κανένα νέο vs-engine.exe.
3. Βοηθός: στείλε ένα μήνυμα με «Ο βοηθός διαβάζει δυνατά» ανοιχτό και «Χωρίς φωνή» → καμία φωνή, κανένα vs-engine.exe.
4. Hub → Κατάσταση / Μοντέλα / Μηχανές / Cloud: άνοιξε όλες τις καρτέλες → κανένα vs-engine.exe.
5. (Προαιρετικό) Εξωτερική εντολή με εκτελέσιμο το vs-engine.exe → «Δοκιμή φωνής» → μήνυμα «Η τοπική φωνή (OmniVoice / vs-engine)
   αφαιρέθηκε στην 2.6.13.1 — το Nyx δεν την ξεκινά. (vs-engine.exe)» και κανένα vs-engine.exe. Μετά γύρνα σε «Χωρίς φωνή».
6. Αν θες: φόρτωσε το Qwen και κοίτα τα t/s στο Hub με το Nyx ανοιχτό (η 2.6.13.1 δεν φορτώνει τίποτα στη GPU για φωνή).

Δ. Hub χωρίς OmniVoice / Voice Studio
1. Hub → Κατάσταση → «Τι τρέχει»: LLM router, Φωνή → κείμενο (whisper), Εικόνα, Ζωντανές σελίδες. ΔΕΝ υπάρχει «Κείμενο → φωνή (OmniVoice)».
2. Hub → Μηχανές: LLM router, Κλειδί router, Φωνή → κείμενο (whisper), Εικόνα. ΔΕΝ υπάρχει η κάρτα «Κείμενο → φωνή · OmniVoice»
   ούτε το «Χρήση OmniVoice». «Για προχωρημένους»: δεν υπάρχει πια η ενότητα «Κείμενο → φωνή» (διαδρομές vs-engine / OmniVoice).
3. Αν τρέχει το Voice Studio στη GPU: στο Hub ΔΕΝ βγαίνει πια «Τρέχει και το Voice Studio … Κλείσε το Voice Studio όταν δουλεύει ο Qwen».
   (Οι άλλες δύο κίτρινες περιπτώσεις — διαρροή σε Shared GPU memory, πτώση t/s — μένουν.)
4. Εργαλεία συστήματος: δεν υπάρχει πια η γραμμή «vs-engine (TTS)».

Ε. Αυτόματο κύλισμα της μπάρας καρτελών (με ΠΡΑΓΜΑΤΙΚΟ ποντίκι) — ίδιο με την 2.6.13
Προετοιμασία: τόσοι πίνακες ώστε το «+N ▾» να έχει τουλάχιστον 10.
1. Πιάσε τη 2η καρτέλα της μπάρας και σύρε τη (χωρίς να αφήσεις) στη ΔΕΞΙΑ άκρη της μπάρας, λίγο πριν από το «+N ▾». Κράτα ακίνητο.
   Αναμενόμενο: μετά από ~¼ δευτ. η μπάρα κυλά, εμφανίζονται καρτέλες που ήταν κρυμμένες· λεπτή λάμψη στη δεξιά άκρη.
2. Πιο κοντά στην άκρη = πιο γρήγορα· λίγο πιο μέσα = πιο αργά.
3. Φέρε τον δείκτη στη μέση της μπάρας → σταματά. Άφησε στο αριστερό μισό μιας καρτέλας που ήταν κρυμμένη → μπαίνει πριν από αυτήν.
4. Ξανά: σύρε στη δεξιά άκρη, όσο κυλά πάτα Esc → σταματά αμέσως, τίποτα δεν μετακινήθηκε.
5. Σύρε μια καρτέλα στην ΑΡΙΣΤΕΡΗ άκρη → κυλά προς τα πίσω και σταματά στην 1η καρτέλα.
6. Σύρε μια καρτέλα πάνω στο «+N ▾» και κράτα ~½ δευτ. → ανοίγει το μενού (δεν κυλά η μπάρα).
7. Μικρό παράθυρο (~1024 πλάτος): Ε1, Ε3, Ε4.

ΣΤ. Μενού «+N ▾» με 25+ κρυμμένους πίνακες
1. Με 25 ή περισσότερους κρυμμένους πίνακες πάτα «+N ▾» → το μενού ανοίγει ΜΕΣΑ στο παράθυρο (κάτω από την μπάρα, με κύλιση), όχι πάνω
   από την οθόνη. Κανονικό και μικρό παράθυρο.

Ζ. Δεν άλλαξαν
1. «Φωνές Windows / συστήματος»: μιλάει όπως πριν (αν τη διαλέξεις).
2. Αναγνώριση φωνής (whisper, μικρόφωνο): όπως πριν.
3. Σύρσιμο καρτελών της 2.6.12.2 (μενού, μπάρα, Διαχείριση), Ctrl+Z / Ctrl+Y, Κάδος, MCP, εξαγωγή / snapshot: όπως πριν.
