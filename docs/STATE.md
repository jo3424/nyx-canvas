## 2. Κανόνες συνεργασίας (ισχύουν πάντα)

**Πώς προχωράμε μια έκδοση**
- Έως **3 παραδοτέα** ανά έκδοση, μία έκδοση τη φορά.
- Κώδικας **μόνο μετά από «Εγκρίνω»** (ή «ξεκίνα» για ό,τι είναι σε αναμονή). Mockup/σχέδιο δεν σημαίνει έγκριση.
- Οι 4 ετικέτες, όπως στο §1. «Επιβεβαιωμένο στο PC σου» μόνο όταν το λέει ο χρήστης.

**Αριθμοί, γλώσσα, ώρες**
- Κάθε αριθμός με πηγή: «από σένα, ημερομηνία» ή πηγή (URL/αρχείο) + υλικό (π.χ. «PC σου, RX 7900 XTX, router b12230 Vulkan»).
- Καμία πρόβλεψη ταχύτητας: μόνο μετρήσεις.
- Ελληνικά κείμενα. Ημερομηνίες DD/MM, ώρες Europe/Athens.

**Τεχνικά όρια**
- **Electron 45.2.3.** Αλλαγή runtime μόνο με πλήρη εγκατάσταση και έγκριση.
- **ctx 32768** σε όλα τα μοντέλα. Δεν ανεβαίνει ποτέ αυτόματα· καμία πρόταση «ανέβασε το ctx».
- Κανένας τεχνητός περιορισμός (μέγιστη απόδοση). Όρια μόνο από πραγματικό ctx/VRAM, ορατά, αλλάζουν από τον χρήστη. Τίποτα σιωπηλό.
- Όλοι οι κανόνες ασφαλείας μένουν: sandbox, contextIsolation, CSP, IPC guard, fuses, ποτέ `--no-sandbox`.

**Δεδομένα και καμβάς**
- **Ποτέ σβήσιμο δεδομένων ή καρτών χωρίς ρητό OK.** Τα δεδομένα του χρήστη δεν τα αγγίζουμε.
- Ο βοηθός **δεν αλλάζει ποτέ τον καμβά** χωρίς εντολή του χρήστη.

**Κλειδιά και αρχεία**
- Υπογραφή patch με το **LEGACY** κλειδί. Το ιδιωτικό κλειδί δεν μπαίνει ποτέ σε repo, zip ή μήνυμα.
- Ποτέ εγγραφή σε παλιούς φακέλους `dist/deliver-*`. Κάθε παράδοση σε νέο φάκελο, χωρίς screenshots.
- **Ποτέ μην αγγίζεις αρχεία του GPU-Voice-Studio** (`C:\Users\admin\GPU-Voice-Studio`). Το Nyx μόνο διαβάζει μοντέλα από εκεί.

**Νομικά και άδειες**
- Μόνο νόμιμα πράγματα.
- Οι άδειες μοντέλων δεν αποκλείουν κανένα μοντέλο: κάρτα με την ακριβή άδεια και αποφασίζει ο χρήστης.
- Σκληρό όριο: όχι σεξουαλικό περιεχόμενο πραγματικών προσώπων χωρίς συναίνεση.

**Αναφορά**
- Κάθε παράδοση λέει: commit, PR, sha256 του patch, πλήθος αρχείων, τεστ, αποκλίσεις, τι δεν επαληθεύτηκε.

| **Κάδος** | `state.bin` μέσα στο nyx.json (`app/js/v26/bin.js`). Τουλάχιστον 30 ημέρες· τίποτα δεν σβήνεται οριστικά χωρίς OK |
| **Backups** | `backups/nyx-YYYY-MM-DD.json`, ένα ανά ημέρα, κρατούνται 14 (`main.js`) |
| **Snapshots** | `snapshots/` (`main/v2.js`, `snap:create`)· το «Μόνο συνδρομές» επαναφέρει από backup/snapshot |
| **Secrets** | `secrets.json` (DPAPI): API keys, token MCP, `router.apiKey` |
| **Router** | `main/procs.js` (εκκίνηση/autostart) + `main/ai.js` (κλήσεις) |
| **Router key** | `main/routerkey.js` (το κλειδί περνά με `LLAMA_API_KEY`). Το `router-api-key.txt` υπάρχει μόνο όσο είναι ενεργή η εκκίνηση με τα Windows |

| **Updates (app-code)** | `%LOCALAPPDATA%\Nyx Canvas\app-code\<έκδοση>` ή `<exe>\NyxData\app-code` (portable), με `state.json` |
