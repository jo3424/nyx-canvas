# Nyx Canvas v2.6.5.2

Patch από την 2.6.5.1. Electron 45.2.3 (αμετάβλητο). Η 2.6.6 μένει κρατημένη για το streaming· η v2.7 μένει παγωμένη.

## Τι προσθέτει

Επέκταση του πρόσθετου **Nyx MCP server** με νέα εργαλεία, χωριστές άδειες και αναίρεση.

1. **Απλά εργαλεία:** `update_card`, `move_card`, `create_reminder`, `list_reminders` / `get_agenda`, `list_boards`, `create_board`, `add_tags`, `link_cards`.
2. **Σύνθετα εργαλεία:** `batch` (όλα ή τίποτα, ένα βήμα αναίρεσης), `group_cards`, `organize_board` (κατά τύπο / ετικέτα / ημερομηνία), `add_image` (τοπικό αρχείο ή http(s)), `summarize_board` (κείμενο μόνο, χωρίς αλλαγή).
3. **Διαγραφή, άδειες, αναίρεση:** `delete_cards` μόνο μετά από επιβεβαίωση μέσα στο Nyx. Χωριστό κουτάκι Ανάγνωση / Γραφή / Διαγραφή. Κάθε αλλαγή γράφεται στο ιστορικό ως «MCP: …» (Ctrl+Z).

Ο διακομιστής μένει στο `127.0.0.1`, με Bearer token. Το Electron, το sandbox και το GPU-Voice-Studio δεν αλλάζουν.

## Εγκατάσταση

Από την 2.6.5.1: Ρυθμίσεις → Ενημερώσεις → «Εγκατάσταση από αρχείο…» → `nyx-2.6.5.1-to-2.6.5.2.zip`.

Δες `tools/accept/ΔΟΚΙΜΗ-ΑΠΟΔΟΧΗΣ-v2.6.5.2.txt` για τα βήματα και ένα παράδειγμα `mcp.json`.
