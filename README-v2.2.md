# Nyx Canvas v2.2 — οδηγός

**Νέα στο v2.2:** το AI Hub συνδέεται πιο σωστά με τους τοπικούς servers (LM Studio, llama-server, Ollama, whisper-server),
λέει **ακριβώς** τι φταίει, βρίσκει μόνο του τα μοντέλα και έχει κουμπιά εκκίνησης. Η φωνή (TTS) έχει έτοιμα πρότυπα και κουμπί «Δοκιμή».
Ο καμβάς και τα δεδομένα σου δεν αλλάζουν.

## Α. Αναβάθμιση από v2.1 (προτείνεται — ~0,3 MB)
1. Κατέβασε το `nyx-2.1.0-to-2.2.0.zip`. **Μην** το αποσυμπιέσεις.
2. Nyx → **Ρυθμίσεις → Ενημερώσεις → «Εγκατάσταση από αρχείο…»** → διάλεξε το zip.
3. Πρέπει να δεις ✅ → «Επανεκκίνηση τώρα». Μετά, στις Ενημερώσεις γράφει **v2.2.0**.
Αν κάτι δεν σου αρέσει: Ρυθμίσεις → Ενημερώσεις → «Επαναφορά στην προηγούμενη έκδοση» (γυρνάς στο v2.1).
Υπάρχει και το `nyx-2.2.0-full.zip` (≈7 MB, όλος ο κώδικας) για οποιαδήποτε παλιότερη 2.1.x — μπαίνει με τον ίδιο τρόπο.

## Β. Νέα εγκατάσταση (portable)
Ίδια με το v2.1: ένωσε τα κομμάτια με το `ENOSE-ME.bat` (ελέγχει MD5), «Εξαγωγή όλων» → `NyxCanvas.exe`.
SmartScreen: «Περισσότερες πληροφορίες» → «Εκτέλεση οπωσδήποτε».

## Γ. AI Hub — τι σημαίνουν τα μηνύματα
* **«αρνήθηκε τη σύνδεση — δεν τρέχει»**: ο server είναι κλειστός ή σε άλλη θύρα.
  * **LM Studio:** καρτέλα **Developer** (πράσινο εικονίδιο αριστερά) → **Start Server** (θύρα 1234),
    ή κουμπί **«Εκκίνηση server LM Studio»** μέσα στο Hub, ή στο τερματικό `lms server start`.
    Χρειάζεται και φορτωμένο μοντέλο (επάνω: «Select a model to load»).
  * **llama-server:** κουμπί **«Εκκίνηση llama-server»** στη γραμμή του provider (χρειάζεται exe + μοντέλο .gguf στο «Τοπικοί servers»).
  * **Ollama:** άνοιξε την εφαρμογή Ollama (εικονίδιο δίπλα στο ρολόι) ή `ollama serve`.
* **«δεν απάντησε εγκαίρως»**: ο server τρέχει αλλά φορτώνει μοντέλο ή κόλλησε — περίμενε λίγο ή επανεκκίνησέ τον.
* **«δεν υπάρχει αυτή η διαδρομή … /v1»**: η διεύθυνση θέλει `/v1` στο τέλος. Το Hub το δοκιμάζει πλέον μόνο του και τη διορθώνει.
* `localhost` / `127.0.0.1` / `::1`: δοκιμάζονται αυτόματα (στα Windows το `localhost` συχνά πάει σε IPv6 ενώ ο server ακούει μόνο IPv4).

## Δ. Τοπικοί servers (whisper-server, llama-server)
* Δίπλα σε κάθε διαδρομή: **🔍 Βρες** (ψάχνει σε Downloads, Έγγραφα, GPU-Voice-Studio, LM Studio, HF cache…) και **📁** για επιλογή με το χέρι.
* Αν το μοντέλο λείπει από τη διαδρομή που έχεις γράψει αλλά υπάρχει αλλού με το ίδιο όνομα, διορθώνεται αυτόματα.
* Πριν την εκκίνηση ελέγχεται: υπάρχει το exe; υπάρχει το μοντέλο; είναι ελεύθερη η θύρα; Αν ο server κλείσει αμέσως, βλέπεις την
  τελευταία γραμμή του log και κουμπί «Log».
* Προαιρετικά: **«Αυτόματη εκκίνηση με το άνοιγμα του Nyx»** για κάθε server.
* Τα γκρι κείμενα μέσα στα κενά πεδία είναι **παραδείγματα**, όχι ρυθμίσεις.

## Ε. Φωνή (TTS) με εξωτερική μηχανή
Ρυθμίσεις φωνής → τρόπος «Εξωτερική εντολή» → διάλεξε **πρότυπο**: VS engine, omnivoice.cpp ή Piper → βάλε exe / μοντέλο / tokenizer (🔍 / 📁).
* **Δοκιμή**: τρέχει μια σύντομη φράση και παίζει τον ήχο — αν αποτύχει, βλέπεις **το πραγματικό μήνυμα σφάλματος** της μηχανής.
* **--help**: δείχνει τις επιλογές του exe, ώστε να διορθώσεις το πρότυπο αν η δική σου έκδοση έχει άλλα ονόματα (π.χ. `--text-file`).
* Για GPU με omnivoice.cpp σε AMD: μεταβλητή περιβάλλοντος `GGML_BACKEND=Vulkan0`.
