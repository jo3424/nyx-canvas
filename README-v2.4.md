# Nyx Canvas v2.4 — οδηγός

**Νέα στο v2.4:** ο υπογραμμιστής/στυλό γράφουν πάνω σε χαρτάκια, ο βοηθός δεν σκεπάζει ποτέ πάνελ, η φωνή μιλάει
καθαρά ελληνικά, vs-engine ως server, Groq (AI + Whisper). Ο καμβάς και τα δεδομένα σου δεν αλλάζουν.

## Α. Αναβάθμιση από v2.3
1. Κατέβασε το `nyx-2.3.0-to-2.4.0.zip`. **Μην** το αποσυμπιέσεις.
2. Nyx → **Ρυθμίσεις → Ενημερώσεις → «Εγκατάσταση από αρχείο…»** → διάλεξε το zip.
3. ✅ → «Επανεκκίνηση τώρα». Στις Ενημερώσεις γράφει **v2.4.0**. Επαναφορά: «Επαναφορά στην προηγούμενη έκδοση».
Το `nyx-2.4.0-full.zip` μπαίνει με τον ίδιο τρόπο σε οποιαδήποτε 2.1.x – 2.3.x.

## Β. Τι άλλαξε
* **Υπογραμμιστής / στυλό / μαρκαδόρος / γόμα / σχήματα / βέλη** δουλεύουν **πάνω** σε χαρτάκια, κάρτες, εικόνες.
  Ό,τι ξεκινάς πάνω σε χαρτί κολλάει σε αυτό και ακολουθεί μετακίνηση & μέγεθος.
* **Βοηθός**: μπαίνει δίπλα στις Ρυθμίσεις/AI/Κατάστημα, ποτέ από πάνω. Σύρε την μπάρα τίτλου για να τον μετακινήσεις,
  τη γωνία πάνω-αριστερά για μέγεθος, διπλό κλικ στον τίτλο = επαναφορά.
* **Φωνή** (Μοντέλα AI → Ομιλία): «Φωνή» με τη γλώσσα κάθε φωνής, Ταχύτητα, Τόνος. Αυτόματα = ελληνική φωνή για ελληνικό κείμενο.
  Χωρίς ελληνική φωνή: **Ρυθμίσεις Windows → Ώρα και γλώσσα → Γλώσσα → Ελληνικά → ομιλία** (το Nyx δείχνει κουμπί), μετά ↻.
* **vs-engine server**: Σύνθεση φωνής → «vs-engine server» → exe, `--model`, `--codec` → **Εκκίνηση & δοκιμή**.
  Το Nyx βάζει μόνο του το `VS_ENGINE_TOKEN`, βρίσκει θύρα/endpoint και δείχνει ό,τι απάντησε ο server.
  Αν δεν βρει endpoint: δες στο launcher/script του `C:\Users\Administrator\GPU-Voice-Studio` ποιο endpoint καλεί και γράψ' το στο «Endpoint σύνθεσης» (π.χ. `POST /v1/audio/speech`).
* **Groq**: Μοντέλα AI → Groq → κλειδί από console.groq.com → Ενεργό. Μοντέλο: llama-3.3-70b-versatile.
  Ομιλία → Αναγνώριση φωνής → **Groq Whisper** (turbo = γρήγορο, large-v3 = ακριβέστερο). Το Groq δεν έχει ελληνική TTS.
  Στο δωρεάν πλάνο, αν πιάσεις όριο, το Nyx περιμένει λίγα δευτερόλεπτα μόνο του ή σου λέει πόσο να περιμένεις.
